# Industrial Fan Anomaly Detection

## Project goal
Learn to build and evaluate an industrial fan audio anomaly detection
system using real audio data from the MIMII dataset.

The project will begin with data exploration and gradually progress
to feature extraction, model development, and evaluation.

## Planned models
- Isolation Forest
- One-Class SVM
- Autoencoder

These are planned experiments, not completed results.

## Project structure
- data/raw/: Original dataset files or local copies
- data/interim/: Intermediate data
- data/processed/: Prepared datasets and extracted features
- notebooks/: Learning and experiment notebooks
- src/: Reusable Python code
- configs/: Experiment settings and configuration
- models/: Saved models and checkpoints
- results/: Metrics, predictions, and comparisons
- tests/: Automated tests
- docs/: Technical notes and project documentation
- reports/: Experiment summaries and academic reports

## Computing environments

## Working principles
- Start with manageable subsets of real data.
- Keep raw data separate from processed data.
- Record experiment settings and evaluation results.
- Do not claim results until experiments have actually been run.
- Keep large datasets and model artifacts out of ordinary Git history.
- Document dataset sources, licenses, and processing steps.
